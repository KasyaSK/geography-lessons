Космічна академія

Навчальний застосунок з історії Всесвіту: від ранньої фізики частинок до утворення Землі. Авторка навчального матеріалу — Каріна Скринченко.

Установити застосунок

APK потрібно саме завантажити, а не намагатися відкрити як звичайну вебсторінку. Файл приблизно 850 КБ.

⬇ Завантажити APK 1.1.0Резервне завантаження через GitHub

Як установити

  1. Відкрийте цю сторінку в Chrome на Android, не у вбудованому переглядачі месенджера.
  2. Натисніть «Завантажити APK», потім відкрийте файл у Завантаженнях або в застосунку «Файли».
  3. Якщо система попросить дозвіл «Установлення невідомих застосунків», надайте його лише браузеру або файловому менеджеру, через який відкрили цей APK.
  4. Підтвердьте «Установити». Після встановлення дозвіл можна вимкнути.
Якщо Android пише «Застосунок не встановлено»: перевірте, чи немає вже встановленої іншої збірки «Космічна академія». У різних тестових збірок можуть відрізнятися підписи. Видалення попередньої версії може стерти локальний прогрес — спочатку перевірте, чи є важливі дані.

Це тестова APK-збірка, не Google Play. Не вимикайте глобальний захист телефона. Якщо інсталяція блокується політикою пристрою, повідомте точний текст помилки.
