# Науковий код України — вебзастосунок

Повноцінний застосунок Astro з серверним API і SQLite (Cloudflare D1). Застосунок не використовує Google Форми; це окрема реалізація, а не редагування Canva Code.

## Можливості
- 6 експозиційних станцій, 16 загадок і вхід учня (ПІБ та клас).
- Перевірка правильності виключно на сервері; 1 бал за правильну відповідь, максимум 16.
- Серверне збереження відповідей, класу, імені, оцінки, дати та тривалості.
- Приватний розділ /teacher: пароль перевіряється на сервері, захищена HttpOnly-сесія, фільтрація за класом, пошук, експорт CSV.
- Результати інших дітей не відкриваються публічно.

## Розгортання
У Webflow Cloud підключіть репозиторій KasyaSK/geography-lessons та гілку science-quiz-cloud. Прив'язка бази D1 оголошена у wrangler.json; SQL-міграція зберігається у migrations/0001_init.sql. Стандартний шлях застосунку — /.

Важливий блокер: Webflow повернув GITHUB_APP_NOT_INSTALLED. Спочатку потрібна явна дія власника акаунта — встановити Webflow GitHub App з доступом до репозиторію. Поки додаток не розгорнуто, ніякі реальні результати через цей код не збираються.

## Безпека та приватність
Учні вносять ПІБ і клас; організатор має повідомити про збирання персональних даних і забезпечити законні підстави, відповідні строки зберігання та видалення. Дозвольте лише мінімально необхідний доступ учителю. Окремі спроби можуть мати однакові імена, тому перевіряйте дублікати.

Пароль адміністратора не міститься в репозиторії у відкритому вигляді. Зберігається лише PBKDF2-хеш. Після розгортання рекомендовано змінити секрет або перейти на входження через керований обліковий запис.

## Дизайн
Використовується власний яскравий STEM-інтерфейс, натхненний дизайн-напрямом Canva. Доступні Canva-конектори не підтримують створення та публікацію Canva Code, тому це окрема серверна реалізація.
