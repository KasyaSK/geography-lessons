# Космічна академія · Android

Справжній нативний застосунок для Android. Не WebView, не PWA, не HTML-обгортка. Android Views + Java, працює офлайн і не вимагає акаунту. Мінімальна версія Android 7.0 (API 24).

## Функціональність
- 7 навчальних експедицій, 21 докладний теоретичний блок і наукові застереження;
- 66 запитань у різних форматах (одна/кілька відповідей, істина/хиба), адаптивне тренування помилок і підсумковий залік;
- 38 карток з інтервальним повторенням;
- 4 конструктори хронології, 23 об'єкти класифікації, 10 детективних наукових справ;
- 5 обчислювальних лабораторій; офлайн світлини в assets/images (за наявності), графічні ілюстрації Canvas як запасний варіант;
- персональний прогрес, XP, статистика, серії днів, усе локально у SharedPreferences.

## Збирання

Через Android Studio: **Open** каталог проєкту, Gradle Sync, **Build > Build APK(s)**.

Командний рядок (Gradle 8.10.2, Android SDK 35, JDK 17+): `gradle :app:assembleDebug`.

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Джерело навчальних даних
Навчальні модулі похідні від HTML-атласу `11/dodatkovi-materialy/istoriia-vsesvitu/` авторства Каріни Скринченко. Авторські матеріали зберігаються в `app/src/main/assets/course.json`. Усе зберігається на телефоні, без серверних акаунтів. Фото ESA/NASA/CERN для освітнього використання атрибутуються у відповідних модулях.
