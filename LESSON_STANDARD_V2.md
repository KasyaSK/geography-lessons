# Стандарт інтерактивних HTML-уроків — v2.0

Автор: Скринченко К.А. • Василівський ліцей «Сузір’я»

## Обов’язкова якість сторінки

- Урок точно відповідає темі, §, очікуваному результату й виду роботи з КТП.
- Одна безперервна адаптивна HTML-сторінка, 35 хв + окреме домашнє.
- Теорія 10–15 хв після залучення учнів, а не на старті.
- До домашнього тесту — щонайменше 6 змістових дій/мікрозавдань.
- Обов’язкові механіки: проблемний старт; реальна карта/дані; лабораторія доказів; сценарій/прогноз; логічна пастка; CER.
- Для 11 класу щонайменше 2 завдання працюють із моделлю, масштабом, невизначеністю, альтернативним сценарієм або достатністю доказів.

## Відео

- Щонайменше 2 якісні українськомовні відео безпосередньо в уроці.
- Окреме обов’язкове українськомовне відео в домашньому блоці.
- Кожне відео має навчальну функцію, питання до перегляду й дію після нього.
- Відео під час уроку разом не більше 7 хв; довгі ролики — фрагментами/таймкодами.
- Російськомовні відео не допускаються.
- Перед публікацією перевіряються назва, канал, мова, зміст, URL і доступність.

## Реальні карти та зображення

- Для тем із просторовими даними — щонайменше 1 реальна карта / ГІС / супутниковий шар.
- Перевага: OpenStreetMap, Google Earth, Copernicus, NASA/ESA, USGS, World Bank, ООН, офіційні українські геопортали.
- Додатково 2–4 змістові реальні візуали: фото, супутникові знімки, графіки, профілі, таблиці, інфографіка.
- Кожен візуал має підпис: що бачимо + джерело/установа + дата, якщо вона важлива.
- Декоративний сток не зараховується як навчальна візуальна опора.
- Ключова карта не замінюється декоративним SVG.
- Перед публікацією перевіряється, що ключові зображення реально завантажуються.

## Домашній блок і тест

- Офіційний е-підручник + точний §.
- Обов’язкове українськомовне відео.
- Три рівні завдання на вибір.
- Тест /10: 10 складних завдань; шлюз ПІБ + клас; результат /10, %, дата/час, скриншот.
- Тест не рахується як основна практична частина уроку.

## Серійна генерація курсу

Якщо поставлено задачу підготувати «решту», «всі уроки» або «повний курс», вона є пакетною й не звужується до найближчого тижня.

Статуси:
`НЕ РОЗПОЧАТО → ДОСЛІДЖЕНО → HTML ГОТОВИЙ → QA ПРОЙДЕНО → GITHUB → PAGES ПЕРЕВІРЕНО`.

Урок зараховується завершеним лише після публічної перевірки GitHub Pages. Позначка «курс завершено» — лише після проходження QA всіма позиціями КТП.
